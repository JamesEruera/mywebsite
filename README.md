# Åkoro Website

This folder is a dependency-free static website intended for GitHub Pages.

To publish with GitHub Pages:

1. Open the repository settings on GitHub.
2. Go to Pages.
3. Set the source to the `main` branch and `/docs` folder.
4. Save the Pages settings.

Before publishing, update the support email in `support.html`, `privacy.html`, and `terms.html` if `support@okoro.app` is not the final support address.
